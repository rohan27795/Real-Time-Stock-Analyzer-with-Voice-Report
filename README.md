# 📈 Stock Market Analyzer & Reporter

> **AI-powered Indian stock analysis with technical indicators, LLM-based SWOT reports, PDF export, and voice narration — all in a single Streamlit app.**

---

## 🚀 Overview

**Stock Market Analyzer & Reporter** is an end-to-end intelligent stock research tool built for retail investors and financial analysts focused on the **Indian equity market**. It combines real-time market data, classical technical analysis, and cutting-edge Large Language Models to deliver insights that would otherwise require multiple paid platforms and hours of manual research.

### The Problem It Solves

Retail investors often struggle with:
- **Information overload** — dozens of tabs, data sources, and tools just to understand one stock.
- **Lack of actionable summaries** — raw charts and numbers don't tell you *what to think*.
- **Accessibility** — financial reports are often locked behind jargon or expensive subscriptions.

This tool collapses that entire workflow into **one button click**: select a stock, pick a time range, and get a complete picture — price charts, volume, RSI, real-time news sentiment, a structured SWOT analysis, a downloadable PDF report, and an audio narration of the full analysis.

### Who It's For

- 📊 **Retail investors** researching NSE-listed stocks
- 🎓 **Finance students** learning technical and fundamental analysis
- 🤖 **AI/ML developers** exploring LLM + financial data integrations
- 🛠️ **Developers** looking to extend the MCP-compatible stock analysis tool

## ✨ Features

### 📊 Technical Analysis
- **Candlestick Price Chart** with 20-day and 50-day Moving Averages
- **Volume Bar Chart** for trading activity visualization
- **RSI (Relative Strength Index)** with overbought/oversold threshold lines (70/30)
- **MACD & Signal Line** computed under the hood for further extensibility

### 🤖 AI-Powered Intelligence
- **Real-Time News Sentiment** via `Gemini 2.0 Flash` — summarizes the 3 latest news headlines for any stock and determines market sentiment
- **SWOT Analysis Report** generated by `GPT-4.1 Nano` (via EURI API) using company fundamentals + live sentiment as context
- Graceful error handling when API keys are missing or API calls fail

### 📄 Export & Accessibility
- **PDF Report Download** — the full SWOT analysis exported as a clean, unicode-safe PDF using `fpdf`
- **Voice Narration** — the SWOT report is converted to an MP3 audio file using Google Text-to-Speech (`gTTS`) and played back directly in the browser

### 🔌 MCP Server Integration
- A **FastMCP server** (`mcp_server.py`) exposes the `stock_analysis` function as an MCP tool, making it consumable by any MCP-compatible AI agent or orchestration framework

### 📡 Dual Data Source Resilience
- Primary data via **Yahoo Finance** (`yfinance`)
- Automatic **Alpha Vantage fallback** if Yahoo Finance is unavailable

## 🏗️ Architecture / How It Works

```
User (Streamlit UI)
        │
        ▼
  main.py  ──────────────────────────────────────────────────────────┐
        │                                                              │
        ▼                                                              │
  analysis.py                                                         │
  ├── yfinance → Historical OHLCV data                                │
  ├── Alpha Vantage → Fallback OHLCV (if yfinance fails)             │
  ├── calculate_indicators() → MA20, MA50, RSI, MACD                  │
  └── get_real_time_sentiment() → EURI API (Gemini 2.0 Flash)        │
                                                                       │
        ▼                                                              │
  llm_report.py                                                        │
  ├── generate_swot_report() → EURI API (GPT-4.1 Nano)               │
  └── save_swot_pdf() → fpdf → swot_report.pdf                       │
                                                                       │
        ▼                                                              │
  voiceover.py                                                         │
  └── generate_voice_report() → gTTS → audio_reports/*.mp3           │
                                                                       │
        └──────────── 4-Tab Streamlit UI ◄──────────────────────────┘
             Tab 1: Price + Indicators Chart
             Tab 2: News Sentiment Summary
             Tab 3: SWOT Analysis + PDF Download
             Tab 4: Audio Voice Report Playback
```

### Data Flow Summary

1. **User selects** a company from the dropdown and a time period, then clicks **Run Full Analysis**.
2. `analyze_stock()` fetches OHLCV history, computes MA/RSI/MACD, and calls the EURI API for live news sentiment.
3. The returned `info` (company fundamentals) and `sentiment` are passed to `generate_swot_report()`, which calls GPT-4.1 Nano to produce a structured SWOT analysis.
4. On success, the SWOT text is simultaneously:
   - Rendered in the **SWOT tab** as formatted markdown
   - Exported to **PDF** via `fpdf`
   - Narrated as an **MP3** via `gTTS`
5. All outputs are surfaced in the Streamlit UI across four tabs.

## ⚙️ Installation & Setup

### Prerequisites

- Python 3.9 or higher
- pip

### 1. Clone the Repository

```bash
git clone https://github.com/rohan27795/Real-Time-Stock-Analyzer-with-Voice-Report.git
cd stock-analyzer
```

### 2. Install Dependencies

```bash
pip install -r requirements.txt
```

> **Note:** `fpdf` is required for PDF generation but is not listed in `requirements.txt`. Install it manually:
> ```bash
> pip install fpdf
> ```
> Also install `fastmcp` if you plan to use the MCP server:
> ```bash
> pip install fastmcp
> ```

### 3. Configure Environment Variables

Create a `.env` file in the project root:

```bash
cp .env.example .env
```

Then fill in your API keys (see [Environment Variables](#-environment-variables) below).

### 4. Run the App

```bash
streamlit run main.py
```

The app will open in your browser at `http://localhost:8501`.

### 5. (Optional) Run the MCP Server

```bash
python mcp_server.py
```

This starts a FastMCP server that exposes `stock_analysis` as a callable tool for AI agents.

## 🔑 Environment Variables

Create a `.env` file (or a `.env.example` for your repo) with the following:

```env
# EURI API Key — used for both Gemini Flash (sentiment) and GPT-4.1 Nano (SWOT)
EURI_API_KEY=your_euri_api_key_here

# Alpha Vantage API Key — fallback data source if yfinance fails
ALPHA_VANTAGE_KEY=your_alpha_vantage_key_here
```

| Variable | Required | Description |
|---|---|---|
| `EURI_API_KEY` | ✅ Yes | Authenticates calls to the EURI API (`api.euron.one`). Used for both sentiment (Gemini Flash) and SWOT generation (GPT-4.1 Nano). |
| `ALPHA_VANTAGE_KEY` | ⚠️ Optional | Used as a fallback if `yfinance` fails to fetch stock data. Get a free key at [alphavantage.co](https://www.alphavantage.co/support/#api-key). |

> 🔐 **Never commit your `.env` file.** Add it to `.gitignore`.

## 🧪 Usage

### Running a Stock Analysis

1. Launch the app with `streamlit run main.py`
2. Select a company from the **dropdown** (e.g., *Infosys*, *Reliance Industries*)
3. Choose a **time period** (1 month to 2 years)
4. Click **🚀 Run Full Analysis**

### Navigating the Results

| Tab | Contents |
|---|---|

```python

from analysis import analyze_stock

```

Or run `python list_models.py` to inspect which models are available on your EURI account.

## 🚧 Challenges & Learnings

### 1. 🔄 API Response Normalization
The EURI API returns responses in an OpenAI-compatible format, but edge cases (missing `choices`, error payloads, unexpected keys) required defensive parsing logic with multiple fallback checks. This reinforced the importance of **never assuming a fixed API response shape**.

### 2. 🧾 PDF Unicode Safety
`fpdf`'s default font (`Arial`) only supports Latin-1 characters. LLM outputs frequently contain em-dashes, curly quotes, and emoji that cause silent encoding failures. The `clean_text_for_pdf()` helper strips unsupported characters character-by-character — a simple but effective workaround.

### 3. ⚡ Data Source Resilience
`yfinance` can be rate-limited or return incomplete data for certain NSE tickers. Building the **Alpha Vantage fallback** path taught the value of designing around third-party fragility from the start, rather than retrofitting resilience later.

### 4. 🔊 Async UX with Streamlit
Streamlit's synchronous execution model means long-running API chains (data fetch → sentiment → SWOT → PDF → TTS) all block the UI. Managing user expectations with `st.spinner` and structured tab rendering was essential for a usable experience.

### 5. 🔌 MCP Abstraction
Wrapping the analysis pipeline as a `FastMCP` tool required thinking about the function's interface — ensuring `analyze_stock()` returned serializable data and had a clean, agent-friendly signature.
